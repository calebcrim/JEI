### Phase 4: Redundancy Rule

**The cardinal rule is identical to the People Dossier task:** If a temporal detail, participant name, financial figure, quote excerpt, EFTA number, or contextual detail about a dated event appears in Source File A and is *not yet present* in your drafted entry from Source File B, **add it**. Only omit information that is 100% identical in fact and specificity.

Watch especially for:
- **The same event described at different granularity** — one file says "in 2011" while another says "April 2, 2011." Use the most specific date as the entry header, note the less specific reference.
- **Different participant lists for the same event** — one file lists two people at a meeting, another lists three. Include all.
- **Financial figures that differ slightly** — "$1.1 billion" vs. "$1.1–1.3 billion" vs. "$1.5 billion total." Include all variants with their source attributions.
- **Quotes from the same email cited differently** — different files may excerpt different portions. Include all excerpted text.
- **Events mentioned in only one source file** — these are critical to capture since they'd otherwise be lost in a synthesis.
